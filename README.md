# WhaleWire Protocol

Premium crypto intelligence platform designed to track smart money on Solana.

## 🚀 Features

- **Live Smart Money Feed:** Directly from Birdeye Protocol nodes.
- **Deep Whale Analytics:** Track any wallet address and see their PnL, win rate, and recent entries.
- **Token Intelligence:** Comprehensive confidence scores based on wallet quality and entry velocity.
- **Coordinated Signals:** Real-time alerts for volume spikes and whale clustering.
- **Elite Design:** Dark terminal aesthetic optimized for speed and clarity.

## 🛠 Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + Framer Motion
- **Data:** Birdeye Public API
- **Fonts:** Outfit (Premium Typography)
- **Charts:** Recharts

## ⚡ Getting Started

1. Set your `BIRDEYE_API_KEY` in `.env.local`.
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)
